# Agent Guidance

## Required Routing

When a user asks to parallelize an AI model, immediately read the complete
master skill at `skills/ai-parallelism-master/SKILL.md` and follow its workflow.

The master skill is the authoritative router. Read each subskill it names in
full before beginning that phase; references to a subskill are not a substitute
for reading it. Do not implement model changes until the master workflow permits
it.
